# Demo

Screens from two simulated tournaments (built with `pnpm --filter @openmat/api demo`):
a youth event grouped by weight (51 kids, 14 groups, 3 mats) and a high school
invitational with seeds and double elimination (63 wrestlers, 6 brackets, 4 mats),
played to mid-event.

- `walkthrough.html`: every screen with captions, grouped by who uses it. Open it in a browser (self-contained).
- `screenshots/`: the individual screenshots.
- `print-brackets.pdf`, `print-bout-sheets.pdf`: the printables, as they come out of the printer.
